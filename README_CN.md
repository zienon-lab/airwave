# AirWave · 隔空互联

> 无需触碰、无需遥控器，一个空中动作即可让设备彼此"认识"并连接。

[English](README.md) | 中文

## 简介
AirWave 是杭州智棱科技（Zienon）隔空手势交互系列中的**"隔空互联"**模块。它通过摄像头识别挥手等空中动作，在免接触的前提下完成设备发现、配对与连接，并可与 [AirMove](https://github.com/zienon-lab/airmove) / [AirTap](https://github.com/zienon-lab/airtap) 联动，把"连接"与"操控"连成一体：先隔空连上设备，再隔空控制它们。

典型场景：用户做出简单的空中动作，即可让手机、电视、大屏或智能家居设备快速建立连接，省去遥控器、扫码或繁琐配对。

## 核心能力
- **手势触发连接**：挥手等动作即可发起设备连接
- **免接触配对**：省去遥控器、扫码与繁琐的手动设置
- **跨设备互联**：手机 ↔ 电视 / 大屏 / 智能家居设备
- **与手势操控联动**：连接后可直接用 [AirMove](https://github.com/zienon-lab/airmove)（光标级控制）、[AirTap](https://github.com/zienon-lab/airtap)（空中点击）继续操作

## 应用方向
> 整理自智棱科技（Zienon）产品资料

- **智能电视**：与电视 / 机顶盒隔空连接并互动
- **智能家居**：手势唤起重与跨设备联动
- **媒体互动**：展厅 / 大屏的隔空连接与内容互动
- **机器人**：隔空指令下发与设备配对

- **手势幼教游戏**：儿童隔空互动与内容连接

## 工作原理
1. 摄像头采集用户动作；
2. 识别挥手等"连接意图"手势；
3. 触发设备发现与配对流程；
4. 建立设备间连接（投屏 / 内容同步 / 控制通道）；
5. 连接后无缝衔接 AirMove / AirTap 的隔空操控。
